# Regression Analysis in R

A collection of university group projects (2025) involving statistical modelling, diagnostics, and model selection in R.

## Projects

### [Project 1 — Plasma beta-carotene](project-1-beta-carotene/)

Study of associations between plasma beta-carotene concentrations and lifestyle and dietary variables in 315 participants. Covers simple and multiple linear regression, log transformations, inference, multicollinearity, influential observations, and model selection using BIC.

See the [project README](project-1-beta-carotene/README.md) for methods, results, reproducibility notes, and contributions.

## Notes

These are collaborative coursework projects. Authorship and individual contributions are described in each project. Original data sources and any reuse restrictions are identified in the project documentation. Observational associations should not be interpreted as causal effects.
